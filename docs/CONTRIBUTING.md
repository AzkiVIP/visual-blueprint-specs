# Contributing

Thank you for contributing to Visual Blueprint.

---

# Before Contributing

Read:

- PRD.md
- ARCHITECTURE.md
- DEVELOPMENT_RULES.md
- UI_GUIDELINES.md

---

# Goals

Contributions should improve:

- Stability
- Performance
- Usability
- Maintainability

---

# Pull Request Requirements

All pull requests must:

- Follow project structure
- Follow naming conventions
- Follow UI guidelines
- Preserve compatibility

---

# Compatibility

Changes must not break:

- Existing Projects
- AIBP Files
- AIBPZ Files

---

# UI Contributions

Must follow:

UI_GUIDELINES.md

Do not introduce:

- Heavy Glow
- Glassmorphism
- Decorative Animations

---

# Node Contributions

Must follow:

NODES.md

New node types require:

- Documentation
- Storage Format
- Import/Export Support

---

# Asset Contributions

Must follow:

ASSET_SYSTEM.md

---

# Documentation

New features require documentation updates.

Code without documentation is incomplete.

---

# Testing Checklist

Before submitting:

- Desktop Tested
- Mobile Tested
- Dark Theme Tested
- Light Theme Tested
- Import Tested
- Export Tested
- Autosave Tested

---

# Bug Reports

Include:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Browser information

---

# Feature Requests

Must include:

- Problem
- Proposed solution
- Benefits
- Trade-offs

---

# Code Style

Follow:

DEVELOPMENT_RULES.md

---

# Final Rule

Consistency is more important than personal preference.
